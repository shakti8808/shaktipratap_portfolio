goboxd – Code Sandbox Execution Service

A Go HTTP service that compiles and runs untrusted code inside isolated sandboxes and returns the result. Supports optional test cases to assert behaviour against expected output — built for safe, multi-language code execution with strict isolation and bounded concurrency.

Plug & Play Language Registry: Language support driven by YAML config — add new languages without touching core logic.

Process Isolation: Uses Linux namespaces and cgroups to sandbox each execution with strict per-request limits for time, memory, and processes.

Bounded Concurrency: Built-in request queuing prevents overload while maintaining throughput under high traffic.

Fully Containerised: Docker Compose setup — no Go toolchain needed on the host for local dev or deployment.

Key Features: Test case assertions, liveness/readiness probes, static analysis, integration tests, and a clean modular architecture.
